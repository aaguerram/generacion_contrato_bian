Como    Admin
Quiero  enviar notificaciones cuando un usuario actualice su número de celular o correo electrónico,
Para      informar el el cambio tanto a los datos anteriores como a los nuevos y prevenir riesgos de fraude



Escenario 1. Notificación al celular o  correo anterior

Dado         que el usuario actualiza su celular o correo electrónico,
Cuando     el cambio  se registra exitosamente,
Entonces   el sistema envíe una notificación al celular o correo anterior

Escenario 2. Notificación al celular o correo nuevo

Dado       que el usuario actualiza su celular o correo electrónico,
Cuando   el cambio se registra exitosamente,
Entonces el sistema envía una notificación al nuevo número de celular o correo.

Escenario 3. Notificación al celular o correo nuevo

Dado        que el usuario actualiza celular y correo electrónico,
Cuando    ambos cambios se procesan exitosamente,
Entonces  el sistema genere las notificaciones cada uno de los cambios

Escenario 4. Mismo esquema de notificaciones

Dado        que existen los mecanismos actuales de notificación
Cuando    se actualicen datos personales,
Entonces el sistema debe mantener  el mismo esquema definido para este tipo de eventos.
